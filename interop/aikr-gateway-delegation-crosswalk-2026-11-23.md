## The one open divergence: absent

The AIKR set has no absent state. Its case D03 (the caller declared no scope, code NO_DECLARED_SCOPE) is reported as check-incomplete, an evaluated outcome. In the AER-1 dictionary, absence is its own outcome: the member is missing altogether, and it must not collapse into an evaluated outcome, because the remedy differs (obtain the missing member, rather than repair or rerun the check). The AER-1 side's recorded position, given on PR #43: add the fourth reporting state (decision unchanged, hold), and move NO_DECLARED_SCOPE to it. The other nine codes in the set's record/checker split stand as placed, including OPAQUE_CONTENT on the checker side: opacity is a relation between the content and the checker reading it, and a record that commits to a form it does not deliver is already a fail-side finding, not a gap.

Adopting the state is the vocabulary group's call, not either package's alone; this file records the AER-1 side's vote and the reasoning, so the divergence is named rather than smoothed over.
